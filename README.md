# 台灣迷宮花園

數感實驗室 2027 冬令營「立體迷宮」課程素材：把台灣兩座真實迷宮重繪成可以玩的網頁。

**線上玩**：https://iweilai0924.github.io/taiwan-maze-garden/

| 迷宮 | 檔案 | 狀態 |
|---|---|---|
| 台北・新生公園迷宮花園（樹籬） | `mazes/xinsheng.html` | 可用 |
| 新北・石門老梅迷宮（紅磚） | `mazes/laomei.html` | 可用 |
| 石門老梅迷宮・數感版（樹幹＋IP 角色） | `mazes/laomei-numeracy-draft.html` | ⚠️ **草稿，需要大量修改** |

`index.html` 是合輯頁，可以切換三座迷宮。每座都有三種視角：俯瞰全景、俯瞰近看、走進迷宮（3D），另外有小地圖、看解答、計時。

## 資料來源與限制

- **新生公園**：依臺北市公園路燈工程管理處的「迷宮花園基本路徑圖」（入口告示牌）重繪，並和國土測繪中心的空拍圖對位檢查過。告示牌是設計圖，現場樹籬可能因為修剪、補植而有出入。
- **石門老梅**：依 2021 年空拍影片的多個角度判讀重繪。程式檢查過每個區域都能從外面走到。牆的長短、粗細是約略值；2021 年之後有沒有改建不清楚。
- 3D 視角裡的樹籬高度、磚牆花紋、樹幹裝飾，都是為了遊戲手感設計的示意，不是實際尺寸。
- `images/` 是重繪的平面圖和解答圖。

## 數感版（草稿）

數感版的樹幹、藤蔓、蘑菇是裝飾，迷宮路線和原版相同。角色（小點、凜、Numnum、Numi、Looppi）為數感實驗室 IP。小點和凜的腿部是暫時補畫的，之後會換正式素材。這個版本還需要大量修改。
